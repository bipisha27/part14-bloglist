# Bloglist

A Bloglist application built with Next.js and TypeScript.

The project includes user authentication, blog management, a database layer using Drizzle ORM, API functionality, and automated end-to-end testing.

## Technologies

* Next.js
* TypeScript
* React
* Drizzle ORM
* Database
* Authentication
* Playwright
* CSS

## Getting Started

Install the dependencies:

npm install

Start the development server:

npm run dev

Then open `http://localhost:3000` in your browser.
